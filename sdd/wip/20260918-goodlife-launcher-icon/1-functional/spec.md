# Especificación funcional — Identidad del launcher

## Objetivo

La aplicación instalada se identifica con la marca GoodLife también cuando el launcher usa el recurso redondo.

## Criterios de aceptación

1. El icono normal y el redondo resuelven a la familia de assets GoodLife existente.
2. No se crean ni reemplazan recursos visuales.
3. El build resuelve los recursos en minSdk 26+.

## Fuera de alcance

Cambios de branding, splash, permisos, comportamiento de launcher o distribución.
